# goods-data
谷店数据地理位置-截止2026年6月

## 说明
之前做了个谷店位置的微信小程序，不过因为没时间运营宣传，放着又白费钱，所以不打算做了。
现在把谷店地理位置数据公开，方便大家使用。
使用的数据库是MySQL 8.x ，版本其实应该无所谓。
坐标适用于腾讯、高德地图。

## 表说明
### administrative_divisions
行政区划表（三级，省、市、区县），国内行政区划代码，包括港澳的，但是不包含台湾省的。    
其中部分地区没有三级区划，比如东莞只有市，没有区县，则会多添加一行区县的数据，名字也叫东莞市，但是编码需要自行调整。

### mall
商圈信息表，部分谷店在商圈内，因此和商圈关联。

### shop
谷店信息表，其中sort_order排名字段都是默认排名，storefront_image、featured_image和inside_image图片的注释是图片的url，其实是图片的id，但是考虑到我没有提供图片，所以这三个字段可以自行清空。   

### shop_tag
谷店-标签关联表

### tag
标签表
